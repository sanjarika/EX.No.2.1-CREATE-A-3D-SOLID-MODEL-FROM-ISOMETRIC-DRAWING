# EX.No.2.1  CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date: 12/10/2026
## Reference number: 26016005
## Name: Sanjarika

## AIM
To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE

1. Open Autodesk Fusion 360, create a new design, select the XY plane, and click on Create Sketch.

2. Using the Rectangle tool, draw a rectangle of dimensions 100 mm × 60 mm. Click Finish Sketch, select the profile, and use Extrude = 30 mm with the operation set to New Body to create the main camera body.

<img width="308" height="305" alt="image" src="https://github.com/user-attachments/assets/4a41689a-656a-4f1e-8510-d001491907cf" />


3. Select the front face of the main body and click on Create Sketch. Draw a circle of diameter Ø50 mm using the Centre Diameter Circle tool and position it according to the reference drawing


4. Click Finish Sketch, select the circular profile, and use Extrude = 20 mm. Set the operation to Join to connect the circular projection to the main body.

<img width="318" height="322" alt="image" src="https://github.com/user-attachments/assets/c9f88f03-768f-4d4c-a704-12eb42820bc3" />

5. Select the top face of the camera body and create a new sketch. Draw the rectangular profile for the raised top section using the dimensions specified in the reference drawing.


6. Click Finish Sketch, select the rectangular profile, and use Extrude to raise it to the required height. Select Join to combine it with the main body.

7. Select the top surface of the raised section and create a new sketch. Draw the required rectangular or square profile according to the reference drawing.

8. Finish the sketch and use Extrude to create the raised feature. Enter the required extrusion distance and select Join if it connects to the existing body.
<img width="413" height="432" alt="image" src="https://github.com/user-attachments/assets/2b5b635a-329e-43ff-b6a6-097a6df7b2b9" />

9. Select the appropriate top face and create a sketch. Draw a circle of diameter Ø20 mm using the Centre Diameter Circle tool.

10. Click Finish Sketch, select the circular profile, and use Extrude to raise it to the specified height. Set the operation to Join to combine it with the camera body.

11. Select the opposite top section and create a new sketch. Using the Rectangle tool, draw the small square feature according to the reference drawing.

12. Finish the sketch and use Extrude to raise the square profile to the required height. Select Join to attach it to the existing body.

13. Select the required edge of the camera body and use the Chamfer tool. 
<img width="367" height="262" alt="image" src="https://github.com/user-attachments/assets/c11ce888-e17e-42ef-909a-4c8d85a35705" />

14. Inspect the completed model and verify the dimensions, including the 100 mm length, 60 mm height, Ø50 mm front circular feature, and Ø20 mm top circular feature. Check that all extruded features are correctly joined and positioned.

15. Finally, switch to Isometric View and compare the completed camera model with the reference drawing. Save the design using the appropriate file name.
